# 無菸城市：推著娃娃車出門的一天

（專案代號：smoke-free　版本：v1.1）

一款諷刺二手菸現況的手機網頁小遊戲。您推著娃娃車出門，沿路遇到抽菸的人：勸阻會被回嘴，拍照檢舉會被踢皮球，等稽查員到場，人早就走了。

**內容純屬虛構，如有雷同，那就是現實。**

## 怎麼玩

直接用瀏覽器開啟 `index.html`，或用 GitHub Pages 開啟。單一檔案，不需要安裝或建置，手機直立操作最順。

每個場景有四種做法，沒有一種是安全的：

- **繞路**：安全但花時間，有時被迫走下人行道。
- **加速通過**：進入閃躲小遊戲，風向會把煙吹到不同車道，轉向前有預警。
- **勸阻**：結果由骰子決定，多半被回嘴，極少數有人聽進去。
- **拍照檢舉**：蒐證有被發現的風險，檢舉之後進入踢皮球迷宮。

畫面上方三條狀態條：寶寶空氣、耐心、時間，任一條歸零行程就提早結束。

## 章節

1. **逛街出門**：社區騎樓、紅綠燈口、超商門口、巷口（找源頭）、公車站牌、公園。
2. **醫院回診**：醫院安全梯間、門口計程車、回程。
3. **診間篇**：換成牙周病醫師，面對滿身菸味、一再承諾戒菸的病人。
4. **下班回家**：學校門口、回家的巷子（找源頭）、夜市入口、社區樓下。

開始前可選章節與社會風氣（公民課本版／現實版）。
